Bikini Engine — минималистичный движок для текстовых квестов на Python. Игра описывается в обычном текстовом файле qwerty.txt простыми командами вида команда<аргумент>, арт лежит в папке art/ в виде ASCII-текста, а развилки делаются через choice/option. Движок читает сценарий построчно, выполняет команды, показывает арт и спрашивает игрока там, где написано choice<вопрос>. Никаких сторонних библиотек не нужно — только стандартная (os, time, sys) и Python 3.10+ (используется match/case).

Установка через установщик: запусти python installer.py, выбери [1] и укажи путь, где создать папку проекта, выбери [2] и введи имя игры, затем введи install. Установщик создаст папку <путь>/<имя_игры>/ с файлами main.py (точка входа), engine.py (сам движок), qwerty.txt (сценарий) и папкой art/ со стартовым артом start.txt. Запуск игры: cd <путь>/<имя_игры> и python main.py. Ручная установка — просто скопируй engine.py, main.py, qwerty.txt и папку art/ в любую папку и запусти python main.py.

Формат сценария: каждая команда на отдельной строке в виде команда<аргумент>, строки без <...> игнорируются. Команда draw<текст> показывает текущий арт, печатает текст по буквам и ждёт ввода (quit или пустой ввод — выход). Команда set_pictures<файл> загружает арт из art/<файл> и запоминает его. Команда choice<вопрос> начинает развилку: показывает вопрос и варианты option, ждёт номер и выполняет только выбранную ветку. Команда option<подпись> задаёт вариант ответа внутри choice — всё, что идёт после него до следующего option или choice<end>, это команды этой ветки. Команда choice<end> закрывает развилку, end<> завершает сценарий.

Пример сценария: set_pictures<start.txt>, затем draw<Ты стоишь на перекрёстке.>, затем choice<Куда пойдёшь?>, затем option<Налево> с командой draw<Ты пошёл налево и нашёл клад!>, затем option<Направо> с draw<Ты пошёл направо и встретил дракона.> и вложенным choice<Дракон перед тобой. Что делаешь?> с вариантами option<Сражаться> (draw<Ты победил дракона!>) и option<Убежать> (draw<Ты убежал. Жив, но без славы.>), закрытым choice<end>, затем option<Нахуй> с draw<Ты пошёл нахуй. Приключение окончено.>, закрытым choice<end>, и в конце draw<Конец.> и end<>. При выборе «Направо» игра покажет дракона и спросит «Сражаться / Убежать», а ветки «Налево» и «Нахуй» не выполнятся.

Арт — это обычные текстовые файлы в папке art/, можно рисовать ASCII-арт в блокноте и подключать через set_pictures<start.txt>. Движок ищет файл по пути art/start.txt относительно папки игры.

Как работает движок: main.py вызывает run_script("qwerty.txt", "art"), который читает файл в список строк и передаёт в run_lines(lines, art_dir). Внутри run_lines идёт по строкам, parse_line превращает "draw<текст>" в ("draw", "текст"), команда draw печатает арт и текст и ждёт ввода, set_pictures читает файл из art/, choice вызывает collect_choice (собирает все option-ветки в список, не выполняя их), показывает меню, ждёт номер и рекурсивно запускает run_lines только для тела выбранной ветки — поэтому вложенные choice работают без дополнительного кода, а end завершает выполнение.

Структура проекта: installer.py (установщик), engine.py (движок), main.py (точка входа), qwerty.txt (пример сценария), art/start.txt (пример арта), README.md (этот файл).

Известные ограничения: нет сохранений и загрузок — игра всегда начинается с начала qwerty.txt; нет флагов и условий (if/else) — только развилки choice; арт только текстовый (ASCII), без картинок; choice не поддерживает возврат в меню после ветки — выполнение идёт дальше по сценарию.
